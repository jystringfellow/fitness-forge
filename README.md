# fitness-forge

Forge your daily workout.

## Starter app (Expo + React Native + TypeScript)

This repo now includes a V1 starter built with Expo Router for iOS, Android, and web.

### Included features

- Two-step workout generation with selectors for time, energy, focus, and attachment
- Guided interval timer with spoken transitions, sound cues, rep tracking, and an optional finisher
- Persistent current workout for returning to an active session
- Searchable exercise library with attachment details and coaching cues

### Run locally (pnpm)

```bash
pnpm install
pnpm start
```

Then open on iOS, Android, or web through Expo.

### Useful commands

```bash
pnpm typecheck
pnpm test
pnpm check:expo
pnpm build:web
pnpm web
pnpm ios
pnpm android
```
